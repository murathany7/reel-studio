# Retro film

**Feel:** warm 70s Super 8. Sunbursts, cream and mustard, chunky stacked type, grain, a gentle weave. Nostalgic and kind.

| | |
|---|---|
| Good for | Lifestyle, food and drink, travel, slow living, craft, anniversaries, anything that wants warmth and memory |
| Not for | Cutting-edge tech, precision claims, dark or urgent subjects |
| Palette | Cream, brown, mustard, teal (the look's). The brand accent becomes the hot colour (`--rf-hot`) |
| Type | Soft fat serif display (`--font-display-retro`: Cooper-style) with stacked offset shadows; a script line for the aside |
| Layout | Centred, symmetrical; a sunburst or a circular badge as the hero; rounded film-gate corners |
| Motion | Slow drift. Titles float up and settle (`power2.out`, 0.9 s), the sunburst turns, the whole picture slowly zooms like a lens pull. Dissolves between scenes. Movement on 18 fps steps feels more like film |
| Texture | Heavy grain (0.12–0.15, 18 fps), `weave`, warm `leaks`, exposure `flicker` (depth ≤ 0.1), warm vignette, `.rf-gate` |
| Engines | GSAP + SVG shapes. Footage plates (graded warm) work very well here. Blender plate for a retro 3D object |
| Sound | Vinyl crackle, a projector whir, warm funk or soul-style bed, a "ding" on the badge |
| Avoid | Clean digital gradients, neon, sharp UI screenshots without a film treatment, cold blues |
